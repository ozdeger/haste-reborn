Haste Reborn
===

Spotlight-style fuzzy search palette for the Unity editor. Open it, type an acronym, and
jump straight to a GameObject in your scene, an asset in your project, or a menu item.
Type `mc` to find `Main Camera`.

This package is the shipped artifact. The development repository — including the test
project, benchmarks and fixture scenes — lives at
<https://github.com/ozdeger/haste-reborn>.

Installation
---

In Unity's Package Manager choose **Add package from git URL** and enter:

```
https://github.com/ozdeger/haste-reborn.git?path=/Packages/com.hastereborn.haste
```

Pin a release by appending a tag, e.g. `#v2.0.0`.

Requires Unity 6000.0 or newer. Editor-only: nothing in this package is compiled into a
player build.

Usage
---

See the [repository README](https://github.com/ozdeger/haste-reborn#readme) for the full
